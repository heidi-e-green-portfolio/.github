# Heidi Green - Portfolio
Sound and music projects

## Includes:   
**CS416P-Clipped:**  
wav.py - Creates "sine.wav" and "clipped.wav", then plays the clipped sine wave directly  
sine.wav - The unaltered 440Hz sine wave  
clipped.wav - The clipped 440Hz sine wave  
README.md - Instructions to build and run the program, and a reflection of the project  

**CS416P-Modem:**   
decoder.py - Bell 103 modem decoder for text messages encoded as audio. WAV file read in, decoded message output and written to message.txt   
message.txt - Decoded message   
README.md - Instructions to build and run the program, and a reflection of the project   

**CS416P-Aleatoric:**   
aleatoric.py - Random song generator and performer. Uses sawtooth wave synthesis    
ALEATORIC.wav - A random song generated with aleatoric.py, with drums and harmony   
requirements.txt - Required installs to be able to run the program   
README.md - Instructions to build and run the program, and a reflection of the project   

**CS416P-Synth:**   
synth.py - Monophonic pulse-wave MIDI synthesizer with AR envelope, transpose, velocity-sensitive amplitude, and one-pole low-pass filter. Connects to MIDI controller   
SYNTH.mp4 - 5 second audio/visual file; demo playing the synth   
requirements.txt - Required installs to be able to run the program   
README.md - Instructions to build and run the program, and a reflection of the project
